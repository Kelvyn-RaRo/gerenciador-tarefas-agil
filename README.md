# gerenciador-tarefas-agil
gerenciador-tarefas-agil
Sistema de Gerenciamento de Tarefas
Objetivo

Desenvolver um sistema simples para gerenciamento de tarefas utilizando conceitos de Engenharia de Software e metodologias ágeis.

Escopo

O sistema permite:

cadastrar tarefas
visualizar tarefas
excluir tarefas
Metodologia

Foi utilizada a metodologia Kanban para organizar o desenvolvimento.

Como executar

Basta abrir o arquivo index.html no navegador.
